# `sonata` (namespace)

The `sonata` namespace is the root name that holds all the other namespaces from Sonata.

## Classes

| Class | Description |
|---|---|
| [`Project`](../classes/project.md) | Represents an initialized and structurally valid Sonata project. |

## Child Namespaces

| Namespace | Description |
|---|---|
| [`sonata::cli`](cli.md) | Contains classes for interacting with the `sn` command. |
| [`sonata::util`](util.md) | Contains generic utility functions, like path parsing. |
| [`sonata::luau`](luau.md) | Contains Luau-related members like VM instances, or table parsing. |
